This repository is an archived mirror of ReactOS's Git-SVN bridge, maintained solely for historical reference and as a base for existing forks. It is no longer active or maintained.

⚠️ Important Notice
This repository is deprecated and read-only. It was originally used to facilitate the transition from Subversion (SVN) to Git for the ReactOS project. For all new contributions, please refer to the official ReactOS Git repository:

reactos.git

📚 Purpose
The ReactOS project migrated from Subversion to Git in October 2017 to improve collaboration and reduce barriers for contributors. This repository served as a temporary bridge during that transition. The SVN repository was turned read-only and kept online at revision r76032.
